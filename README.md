# SciSpell — an NLP correction & sentiment laboratory

**Live app:** *(link coming in Step 2)* · Built from first principles, measured at every step.

Two engines, one discipline: a **spelling corrector** that learned English from
Darwin, Einstein and Faraday — then got re-armed with a modern news language
model — and a **sentiment engine** spanning a classical ensemble and a
fine-tuned transformer. Every design decision in this repo was made by
benchmark, and three designs were killed by their own measurements along the way.

## How it works

**Spelling.** A two-layer dictionary (376k words) separates *existence* from
*probability*, killing false positives by construction. Candidates come through
tiered channels: keyboard-weighted Damerau edits, a Soundex phonetic index, and
a consonant-skeleton index for texting-style compression (`hv → have`).
Ranking is noisy-channel: error cost × blended context, where context mixes a
Victorian-science bigram model with one trained on 6M tokens of 2023 news —
and a data-derived **trust map** demotes 20k dictionary junk words (`hv`, `sh`,
`ws`) to context-checkable status, caught when the surrounding sentence
corroborates.

**Sentiment.** A soft-vote ensemble (TF-IDF logistic regression + NB
log-count-ratio features) trained on a **deduplicated, leakage-audited** IMDB
split plus 1,000 adapted product/restaurant sentences; beside it, DistilBERT
fine-tuned one epoch on the same mix. The app shows exact per-feature
explanations for the linear family and an abstain band where confidence is
genuinely low — because our error autopsy showed 76% of mistakes were
low-confidence.

## The method (what makes this a laboratory)

- **Measure before designing.** The dictionary trust map, the suspicious-word
  margin, the smoothing constants, the channel design — all chosen by sweep or
  tournament, never taste.
- **Refutations are kept, not hidden.** A pure frequency threshold, a merged
  candidate pool (twice), and an `<unk>`-leaking scorer all died in these
  notebooks; the evidence is preserved.
- **The test set is spent, not browsed.** Every headline number is a single,
  final touch of the official test split per shipped model.
- **Everything rebuilds.** Every notebook downloads its own data; every model
  is an artefact with provenance.

## Run it

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

First run downloads NLTK's VADER lexicon automatically. The deep sentiment mode
(DistilBERT) is optional: run `notebooks/11_V2_Classifier.ipynb` cells 14–16 to
train it locally (~6 min on Apple Silicon), and the app detects it on restart.
